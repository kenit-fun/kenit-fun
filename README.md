# 🎮 KenitFun

> **A collection of whimsical digital amusements, vintage toys, puzzles, and mini-games — free to play in your browser.**

🌐 **Live Website:** https://www.kenit.fun/

KenitFun is a growing collection of lightweight, browser-based games and interactive experiences designed to be simple, fun, nostalgic, and instantly playable.

No downloads. No installations. Just open a game and play.

## 🤝 Contributing

Ideas, suggestions, bug reports, and contributions are welcome.

If you have an idea for a fun browser game or interactive experience, feel free to open an issue or submit a pull request.

### Contribution Process

1. Fork the repository.
2. Create a new branch.

```bash
git checkout -b feature/my-new-game
```

3. Add your game or improvement.
4. Test it on desktop and mobile.
5. Commit your changes.

```bash
git commit -m "Add new game"
```

6. Push your branch.

```bash
git push origin feature/my-new-game
```

7. Open a Pull Request.
