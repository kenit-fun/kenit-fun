KenitFun Game Library

This catalog brings together word and logic puzzles, short arcade challenges, quizzes, and interactive toys made for a browser break. Games open without an account or download; each page explains its own controls and objective. Some games save scores in this browser, while Global Telegraph uses a public live message channel.

Stories and playful tools

Choose your route through Midnight Station, explore the interactive Rotary Phone, or experiment without a score in Reality Slider.

The games are independent experiments, not a single account-based service. A few titles connect to external services: Global Telegraph publishes messages to a shared public stream, and the hourly poll is an informal, non-scientific demo. Check each game's guide and the privacy policy before using those features.
