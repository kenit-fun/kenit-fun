KenitFun Game Library

This catalog brings together word and logic puzzles, short arcade challenges, quizzes, and interactive toys made for a browser break. Games open without an account or download; each page explains its own controls and objective. Some games save scores in this browser, while Global Telegraph uses a public live message channel.

Find a game that fits your break

Words and clues

Find one word that fits three clues in Triple Threat, work through a timed word cipher in Word Cipher, or type a short answer to each prompt in The Riddle Vault. These are good choices if you want to think between turns instead of steering in real time.

Timing and movement

Switch between three lanes in Orbit Outrun, steer a bouncing jumper with touch or keyboard in Skyline Ninja Rush, test a single visual response in Cyber Reflex, or aim each shot in Neon Cyber Dunk. The instructions on each game page list its supported controls.

Quieter puzzles

Remember revealed pairs in Zen Stone Memory Match, choose connected groups on the board in Prism Pop, or carefully place stones with a mouse or touch screen in Zen Stone Balancer. These games reward observation and planning more than quick reactions.

Stories and playful tools

Choose among endings in Midnight Station, dial through an interactive directory in The Rotary Phone, or experiment without a score target in Reality Slider and The Chaos Engine.

The games are independent experiments, not a single account-based service. A few titles connect to external services: Global Telegraph publishes messages to a shared public stream, and the hourly poll is an informal, non-scientific demo. Check each game's guide and the privacy policy before using those features.

A few practical starting points: Prism Pop gives you 18 moves to reach the opening score goal; Orbit Outrun is a short survival run with three hull points; and Retro Trivia presents a shuffled set of questions. Records are local to the browser when a game offers saving; they are not a shared leaderboard or account.
